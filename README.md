# ChurnSense AI — Customer Churn Prediction System

**ChurnSense AI** is an end-to-end machine learning application designed to predict customer churn and identify customers who are at risk of leaving. Built as my final-year Data Science project, it combines predictive modeling, data analysis, explainable insights, and a Flask-based web interface into a practical customer analytics solution.

### Key Features

* Customer churn prediction with probability scoring
* Explainable AI-based risk assessment
* Feature importance analysis
* Single customer prediction
* Bulk CSV prediction and processing
* Churn analytics dashboard
* Prediction results export

### Technology Stack

**Python | Pandas | NumPy | Scikit-learn | Random Forest | Flask | HTML | CSS | JavaScript**

The model is trained on the **IBM Telco Customer Churn dataset** and achieves approximately **79.5%–80.5% validation accuracy**.

### About the Project

This project demonstrates the complete machine learning workflow, from data preprocessing and feature engineering to model training, evaluation, prediction, and deployment through a web application.
